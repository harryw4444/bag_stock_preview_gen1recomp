### 🛍️ Bag Stock Preview
Shows a handy preview at the bottom of the shop menu displaying how many of the selected item you currently have in your bag before you purchase.

## 🛠️ How to Install

1. Download the `.zip` file for the mod.
2. Open **Gen1Recomp**.
3. Go to the **Mods** menu and select **Import mod.zip**.
4. Choose the `.zip` file and make sure it is enabled!
